# 当前实现与李继刚 ljg-roundtable 的差异

Roundtable Lab 受李继刚 [`ljg-skill-roundtable`](https://github.com/lijigang/ljg-skill-roundtable) 启发，但目标不同：原版是一个轻量 Claude Code skill，强调主持人引导和多人物辩证；本项目是本地 Python 工具，强调每个人物基于本地材料库检索证据后再发言。

## 已贴近的部分

- 主持人会提炼本轮核心争议点。
- 主持人会输出 ASCII 思考框架图。
- 主持人会提出下一层引导问题。
- 参会角色现在会看到前文，不能只基于自己的知识库孤立发言。
- 同一轮内后发言者能看到前面人物发言。
- 后续轮次会看到前面轮次的完整 transcript。
- 本地保存完整 transcript，并按 `round-01/`、`round-02/` 分轮保存材料、发言、稽核和主持人综述。
- 第一轮默认使用开场定义问题。
- 人物发言提示已强制行动标签和 `**简言之**：`。
- 网页已支持 `可 / 深入此节 / 引入新人物 / 止`。
- `止` 会生成全局总结、完整知识网络和开放问题，并保存为 `knowledge-network.md`。
- 主持人会在每个 turn 前动态选择下一位发言者，并可提前结束本轮。

## 当前仍有的差异

1. 选人机制不同

李继刚原版要求根据议题自动提议 3-5 位真实历史/当代人物，并说明 MBTI、核心立场、选择理由、张力网络。当前实现按用户取舍保留手动人物列表。

2. 保存格式不同

李继刚原版保存 org-mode，并要求所有发言、ASCII 图、主持人综述“一字不差”。当前实现保存 Markdown，更适合 Obsidian；完整 transcript 已保留，但不是 org 文件。

3. 证据驱动机制是本项目增强，不是李继刚原版自带

当前实现增加了每个人物独立知识库、embedding 检索、证据面板、稽核员。这比原版提示词更适合严肃研究，但也改变了原版“轻量提示词圆桌”的性质。此项按用户取舍保留。

## 推荐下一步

- 如果需要更严格贴合原版，可增加 org-mode 导出。
- 如果需要更强研究体验，可把 `knowledge-network.md` 自动导出到 Obsidian。
- 如果需要更接近“动态发言”，可允许同一人物一轮中多次发言，而不是每轮最多一次。
